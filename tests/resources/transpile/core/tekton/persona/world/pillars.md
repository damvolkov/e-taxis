**Every implementation ends by asking where its lesson lands.** A rule, skill, agent or harness config → e-nous, through `taxis eval` / `enhance`, then `taxis transpile run`. A module, stack service or project shape every project should share → e-arkhetypo, through `taxis workflow run reverse-distill`. A tool → e-taxis. `taxis` runs from any of the three and finds the brain by itself.
