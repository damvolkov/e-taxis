**The Triad** — three pieces, one system: the will, the body, the hand. Each change lives in its piece, never in another's:

- **e-nous** — the will, the brain (νοῦς, *mind*): this corpus — its two hemispheres, tekton (the engineer, technical) and nomos (the polymath, human), with their persona, skills, agents, commands, workflows, evals and specs. Data, plus only the code the harnesses run as part of the brain (hooks). Doctrine changes here.
- **e-arkhetypo** — the body, the forms: data, never tooling. Project blueprints (`projects/python/`, `projects/rust/`), self-hosted stacks (`stack/`), CI/CD sources (`infra/`) and the template registry `projects/templates.yml`. Public: `github.com/damvolkov/e-arkhetypo`. Template changes here.
- **e-taxis** — the hand, the act, the bridge: the deterministic engine (`taxis`) that turns the archetypes into running things — assembles `.github/` from `infra/`, materializes core into projects, generates new projects, gates drift — and all the code that operates the brain: transpile, eval, enhance, workflows, distill, installs. Tool changes here.

The will decides, the hand executes, the body holds the forms.
