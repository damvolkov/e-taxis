Agents are named by two laws. **The id is `<base>-<action>`**: a base role of the corpus (`architect`, `auditor`, `builder`, `integrator`, `operator`, `orchestrator`, `probe`, `researcher`, `scout`, `speckeeper`, `verifier`, `local`) and one word for the concrete thing it does — `scout-codegraph`, `auditor-verdict`, `researcher-digest`. A new base role is a single word, created only when no existing one fits. **The persona — the inner name — is Elvish**, Quenya by default, chosen for what it says of the agent's work.
