# bibliography — algorithmic reference by level

The shared canon behind every `algo-*` skill. Each domain skill cites the subset (and the concrete chapters) it relies on.

| Level | Work | Use in the skills |
|---|---|---|
| Foundations | *Introduction to Algorithms* (CLRS, 4th ed. 2022) | Complexity and correctness |
| Foundations | *Algorithms* — Jeff Erickson (free) | Recursion, backtracking, DP as a way of thinking |
| Foundations | *Algorithms Illuminated* — Tim Roughgarden | Synthesis of paradigms |
| Engineering | *The Algorithm Design Manual* — Steven Skiena (3rd ed.) | Format of the need → algorithm catalog |
| Engineering | *Guide to Competitive Programming* — Antti Laaksonen; cp-algorithms.com | Compact implementations |
| Python | *High Performance Python* — Gorelick & Ozsvald (3rd ed. 2025) | Profiling, structures, NumPy, compilation, > RAM |
| Python | *Fluent Python* (2nd ed.) — Luciano Ramalho | Real cost of the data model |
| Python | *Python Algorithms* — Magnus Lie Hetland | Idiomatic algorithmics |
| Python | Python Wiki: TimeComplexity | Cost of builtin operations |
| Massive data | *Algorithms and Data Structures for Massive Datasets* (Manning, 2022) | Streaming, sketches, external memory |
| Massive data | *Mining of Massive Datasets* — Leskovec, Rajaraman, Ullman (free) | MinHash, LSH, streams |
| Massive data | *Probabilistic Data Structures and Algorithms for Big Data Applications* — Andrii Gakhov | Bloom, HLL, Count-Min |
| Hardware | *Algorithms for Modern Hardware* — Sergey Slotin (free) | Cache, SIMD, why Rust/NumPy win |
| Systems | *Designing Data-Intensive Applications* — Martin Kleppmann | Bridge to Layer 3 (LSM, B-trees, partitioning) |
| Numeric | *What Every Computer Scientist Should Know About Floating-Point Arithmetic* — David Goldberg | Numerical stability |
| Optimization | *Convex Optimization* — Boyd & Vandenberghe (free) | Basis of continuous optimization |
